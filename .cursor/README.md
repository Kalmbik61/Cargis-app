# 🚀 CURSOR AGENTS - BITRIX FRONTEND

## Быстрый старт

### 1. Активация агента
Просто начните сообщение с `@frontend` или используйте ключевые слова:
```
@frontend создай модальное окно
верстка из Figma нужна помощь
нужен новый компонент селектора
```

### 2. Автоматическая активация
Cursor автоматически активирует агента при упоминании:
- модальное окно, модалка
- верстка, макет, Figma  
- компонент, селектор, дропдаун
- адаптивность, мобильная версия
- SCSS, стили, CSS
- JavaScript, jQuery
- Bitrix, PHP шаблон

## Примеры использования

### 🎨 Создание модального окна
```
@frontend создай модальное окно для расчета доставки с валидацией формы
```

### 📐 Верстка из Figma
```
@frontend сверстай карточку товара из макета [Figma URL] с hover эффектами
```

### 🧩 UI компонент
```

```

### 🔗 Bitrix интеграция
```
@frontend интегрируй новый компонент с существующим шаблоном Bitrix
```

## Что делает агент

### ✅ Автоматически:
- Анализирует задачу и существующий код
- Создает план выполнения
- Генерирует код с соблюдением стандартов
- Предлагает структуру файлов
- Проверяет совместимость с Bitrix
- Обеспечивает адаптивность
- Документирует решение

### ✅ Соблюдает принципы:
- BEM методология для CSS
- ES6+ современный JavaScript
- Mobile-first подход
- Кроссбраузерность (IE11+)
- Семантичная HTML разметка
- Оптимизация производительности
- Доступность (a11y)

### ❌ Никогда не делает:
- Не создает новую PHP логику
- Не использует React/Vue/Angular
- Не ломает существующие стили
- Не игнорирует Bitrix архитектуру
- Не создает неадаптивные компоненты

## Советы по работе

### 💡 Для лучших результатов:
1. **Будьте конкретны** в описании задач
2. **Предоставляйте контекст** - ссылки на макеты, существующий код
3. **Указывайте требования** - браузеры, устройства, особенности
4. **Описывайте интеграцию** - как должно работать с Bitrix

### 🎯 Примеры хороших запросов:
```
✅ @frontend создай адаптивное модальное окно для формы заказа с:
   - Валидация email, телефон, имя
   - Анимация slide-down
   - Закрытие по ESC и клику вне окна  
   - Интеграция с Bitrix веб-формой ID=1
   - Поддержка IE11+

✅ @frontend сверстай из Figma компонент новостей:
   - Ссылка: figma.com/file/xyz
   - Сетка 3 колонки на десктопе, 1 на мобильном
   - Hover эффект подъема карточки
   - Ленивая загрузка изображений
   - BEM классы
```

### ❌ Примеры плохих запросов:
```
❌ сделай красиво
❌ нужна форма  
❌ исправь баг
❌ как в том проекте
```

## Устранение проблем

### Если агент не активируется:
1. Проверьте, что файлы в `.cursor/` существуют
2. Используйте явную активацию `@frontend`
3. Перезапустите Cursor IDE

### Если результат не соответствует ожиданиям:
1. Добавьте больше контекста в запрос
2. Укажите конкретные требования
3. Приложите ссылки на макеты/примеры
4. Опишите интеграцию с существующим кодом
