# 🤖 СИСТЕМА АГЕНТОВ ДЛЯ CURSOR

## ГЛАВНЫЙ АГЕНТ: Frontend Developer

### 🎯 Активация агента
Для активации специализированного режима используй одну из команд:

```
@frontend создай модальное окно для расчета доставки
@frontend-dev сверстай компонент из Figma
@bitrix-frontend добавь новый селектор городов
```

### 📋 Специализированные команды

#### 🎨 Разработка функционала
```
@frontend создай [описание функционала]
@frontend добавь интерактивность для [компонент]
@frontend реализуй калькулятор [тип калькулятора]
```

#### 📐 Верстка из макетов
```
@frontend сверстай из Figma [ссылка или описание]
@frontend адаптируй под мобильные [компонент]
@frontend создай адаптивную сетку для [блок]
```

#### 🧩 UI компоненты
```
@frontend создай компонент [тип компонента]
@frontend стилизуй [элемент] в стиле [описание]
@frontend создай переиспользуемый [компонент]
```

#### 🔗 Bitrix интеграция
```
@frontend интегрируй с Bitrix [компонент]
@frontend поддержи стиль PHP в [файл]
@frontend адаптируй под шаблон Bitrix [компонент]
```

## АВТОМАТИЧЕСКИЕ ТРИГГЕРЫ

Cursor автоматически активирует агента при упоминании:
- "модальное окно", "модалка"
- "верстка", "макет", "Figma"
- "компонент", "селектор", "дропдаун"
- "адаптивность", "мобильная версия"
- "SCSS", "стили", "CSS"
- "JavaScript", "jQuery", "интерактивность"
- "Bitrix", "PHP шаблон"

## КОНТЕКСТНЫЕ РОЛИ

- Пользовательский опыт

Режим разработчика - фокус на:

### 🔧 Integration Mode
```
Режим интеграции - фокус на:

- Обратная совместимость
```

## БЫСТРЫЕ КОМАНДЫ

### Создание структуры компонента:
```
@frontend scaffold [название-компонента]
```
Создаст:
- HTML структуру
- SCSS файл с BEM классами  
- JS модуль
- Документацию

### Анализ макета:
```
@frontend analyze [Figma URL]
```
Проанализирует и предложит:
- Структуру HTML
- CSS Grid/Flexbox подход
- Брейкпоинты
- Оптимизации

### Оптимизация кода:
```
@frontend optimize [файл или компонент]
```
Проведет:
- Рефакторинг кода
- Оптимизацию производительности
- Проверку на соответствие стандартам
- Предложения по улучшению

## ПРИМЕРЫ ИСПОЛЬЗОВАНИЯ

### Пример 1: Создание модального окна
```
@frontend создай модальное окно для формы обратной связи с:
- Валидация полей email и телефон
- Анимация появления
- Закрытие по клику вне окна
- Адаптивность под мобильные
- Интеграция с Bitrix формой
```

### Пример 2: Верстка из Figma
```
@frontend сверстай карточку товара из макета:
- Ссылка: [Figma URL]
- Требования: hover эффекты, адаптивность, BEM
- Интеграция с каталогом Bitrix
- Ленивая загрузка изображений
```

### Пример 3: UI компонент
```
@frontend создай переиспользуемый селектор с:
- Поиск по опциям
- Мультиселект
- Кастомный дизайн
- API для загрузки данных
- Доступность (ARIA)
```

## АВТОМАТИЧЕСКИЕ ПРОВЕРКИ

Агент автоматически проверяет:
✅ Соответствие BEM методологии
✅ Адаптивность (mobile-first)
✅ Кроссбраузерность
✅ Производительность
✅ Доступность (a11y)
✅ Совместимость с Bitrix
✅ Качество кода (ES6+)
✅ Оптимизация ресурсов
